# RC-Jet
A project to build a RC jet using a custom-built motor, flight controller based on a RP Pico and 3D printed parts.

## Goals

- Build a radio controlled jet from from the shelf parts, including a DIY DLBC motor, RP Pico based flight controller, common sensors and 3D printed parts
- The fan speed should be set continuously
- Functional flaps (depending on the chosen jet model)
- Emergency parachute
